# Unsupervised and Reinforcement Learning (URL) Coursework
**Author:** Bruno Sánchez Gómez

This repository contains the coursework for the Unsupervised and Reinforcement Learning (URL) course, part of the Master's in Artificial Intelligence (MAI) program at UPC-BarcelonaTech. The project is divided into two main parts:

1.  **Coursework 1:** An implementation and evaluation of the Path Integral Clustering (PIC) algorithm.
2.  **Coursework 2:** A comprehensive review and presentation of the StackGAN++ paper.

## Coursework 1: Path Integral Clustering (PIC)

This coursework focuses on implementing the Path Integral Clustering (PIC) algorithm from scratch and evaluating its performance on image datasets.

### Source Code

The source code for the PIC implementation is located in the `Coursework1/src/` directory. The main logic is within a Jupyter Notebook.

To run the code, navigate to the `Coursework1/` directory, create a virtual environment, and install the dependencies from `requirements.txt`. Then, you can run the `main.ipynb` notebook.

### Report

A detailed report for this coursework can be found in the `Coursework1/report/` directory. The main file is `main.tex`, which compiles into the final report document, `main.pdf`. This document discusses the implementation in depth and presents the results.

### Results

The `Coursework1/results/` directory contains the outputs from the PIC algorithm's evaluation. This includes clustering performance metrics such as silhouette scores, and NMI scores, as well as plots visualizing the results.

## Coursework 2: StackGAN++ Review

This coursework consists of a review of the paper "StackGAN++: Realistic Image Synthesis with Stacked Generative Adversarial Networks".

### Presentation

The presentation slides and related materials for the StackGAN++ review are located in the `Coursework2/presentation/` directory. The main LaTeX file for the presentation is `presentation.tex`.
